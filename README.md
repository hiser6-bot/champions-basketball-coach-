# Champions Drill Decks Basketball Prototype v0.1

Phone-first PWA prototype with 12 basketball drills, drill detail screens, favorites, practice builder, quick practice, drill timers, local storage, and offline service-worker support.

## GitHub Pages
Upload these files to the root of a GitHub repository, enable Settings > Pages > Deploy from a branch, and select the `main` branch/root folder.

## Visual note
The generated Two-Ball Rhythm Dribble visual is included as the first dedicated drill image. The remaining prototype drills use the shared concept artwork as temporary placeholders until dedicated visuals are produced.
